# PySpark Practice - Практическое руководство по PySpark

Этот проект представляет собой практическое руководство по работе с Apache PySpark в Google Colab. Проект демонстрирует основные концепции обработки больших данных с использованием PySpark API.

## Описание проекта

PySpark - это Python API для Apache Spark, фреймворка для распределенной обработки больших данных. Данный проект содержит примеры работы с различными функциями PySpark для анализа данных, трансформаций и SQL-запросов.

## Используемые PySpark концепции

### Основные концепции

- **Создание Spark Session** - инициализация и настройка Spark-приложения
- **DataFrame операции** - select, filter, groupBy, agg для манипуляции данными
- **SQL запросы** - использование SparkSQL для выполнения SQL-запросов на DataFrame
- **Window Functions** - оконные функции для сложных аналитических операций (ROW_NUMBER, LEAD, LAG, агрегации)
- **UDF (User Defined Functions)** - пользовательские функции для кастомной обработки данных
- **Joins** - объединение датафреймов различными способами
- **Работа с JSON данными** - чтение и обработка JSON-структур
- **Агрегации и трансформации** - groupBy, collect_list, collect_set, pivot/unpivot операции

### Продвинутые концепции

- **Caching и Persistence** - кэширование данных в памяти/на диске для ускорения повторных вычислений
- **Partitioning** - оптимизация через repartition() и coalesce() для распределенной обработки
- **Broadcast Variables** - эффективная передача небольших данных на все узлы кластера

### Дополнительные возможности

- Чтение CSV и Parquet файлов
- Работа с пропущенными значениями (NULL handling)
- Regex операции для обработки текста
- Преобразование Pandas DataFrame в Spark DataFrame
- Дедупликация данных с помощью оконных функций
- Создание временных представлений (TempView)
- Расчет скользящих средних и метрик активности пользователей
- Unpivot операции (stack функция)
- Explode для развертывания массивов
